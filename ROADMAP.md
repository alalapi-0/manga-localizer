# Roadmap

## V0.1 — OCR reviewer

- Portable projects, nested image import, page list, canvas regions, real Japanese OCR
- Source/translation editing, reading order, confidence, autosave, session undo/redo
- Text JSON export and persistent basic jobs

## V0.2 — baseline localization workbench

- Manual/mock/dictionary/OpenAI-compatible translation with bounded context
- OpenCV mask/inpainting, Pillow horizontal/vertical typesetting, preview modes
- Batch processing/export, retries, status filtering, security tests, browser tests, public documentation

## V0.3 — quality providers

- Optional MangaOCR/PaddleOCR and improved balloon/text detection
- Optional LaMa-class inpainting behind explicit model download and licensing checks
- Translation memory, stronger glossary consistency, richer page-level context controls
- Better vertical punctuation, ruby handling, and reusable typography presets

## V0.4 — desktop distribution

- Tauri evaluation and signed macOS/Windows/Linux packaging
- Native directory picker, file watching, crash diagnostics, and portable-project migration tooling

## Later research

- Licensed font matching, editable PSD-like export, artistic sound-effect redraw
- PDF/EPUB workflows, opt-in encrypted sync, and collaboration

Roadmap items are intentions, not current capabilities or delivery commitments.
